## Security constraints

- Fail-closed staging launcher uses `MONGODB_STAGING_URI`, refuses non-`gazu_ai_staging`, leaves the user's original URL unchanged.
- All API returns draw from real available and published Mongo catalogue; no autogenerated products, prices, or stock.
- Chat, visual search and personalized discovery are authenticated and rate limited; chat reads and deletes are filtered by current owner.
- Visual images are ephemeral, MIME/magic-byte checked and limited to 3 MB. Provider requests may consume Gemini quota.
- Separate browser E2E acceptance pending user's Mac execution.
